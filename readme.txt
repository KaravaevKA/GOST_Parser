# Автоматический подбор квалитетов по 3D-модели

## Описание
Программа загружает STEP-модель, находит цилиндрические поверхности, определяет их диаметры,
подбирает номинальный размер (округлением до целого) и определяет, в какой квалитет (h9, h8 и т.д.)
попадает фактический размер, используя данные из ГОСТ 25347 (файл `gost_h_h_tolerances.json`).

## Установка
1. Создайте виртуальное окружение Python 3.11.
2. Установите CadQuery: `pip install cadquery`
3. Поместите STEP-модель в папку `data` и укажите её имя в `auto_tolerance.py`.

## Использование
Запустите `auto_tolerance.py`. Программа выведет найденные цилиндры и рекомендуемые квалитеты.

## Структура
- `auto_tolerance.py` – главный скрипт
- `src/cadquery_analyzer.py` – модуль для извлечения цилиндров
- `data/gost_h_h_tolerances.json` – данные допусков
