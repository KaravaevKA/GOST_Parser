Программа для анализа цилиндрических поверхностей STEP-модели

Запуск оконной версии
---------------------
1. Установите Python и зависимости из requirements.txt:
   python -m pip install -r requirements.txt
2. Для окна интерфейса используется PySide6, а для встроенного 3D-просмотрщика —
   VTK. Они устанавливаются предыдущей командой вместе с остальными пакетами.
3. Из папки проекта выполните:
   python main.py

В окне отображаются цилиндрические поверхности и их диаметр и осевая длина.
Поверхность можно выбрать в таблице или нажатием на неё в 3D-модели.
Для выбранной поверхности программа показывает квалитеты для предполагаемого
номинального размера. Подпись рядом с квалитетом показывает, попадает ли
диаметр STEP-модели в его поле допуска. Пользователь может выбрать любой
квалитет из списка или оставить поверхность без назначения.

Назначения сохраняются автоматически в JSON-файле внутри
data/assignments. Отдельный файл создаётся для каждой версии STEP-модели.
Кнопка «Сохранить назначения» позволяет сохранить их вручную.

Расчёт припусков и размерная цепь
---------------------------------
1. Откройте STEP-модель и нажмите «Расчёт припусков и цепи…».
2. На вкладке «Переходы и припуски» задайте для заготовки смещение ρсм,
   удельную кривизну Δк и расчётную длину L. Добавьте переходы по порядку и
   задайте Rz, глубину дефектного слоя T, коэффициент Ky, ошибки базирования
   и закрепления, тип обрабатываемого размера и наличие переустановки.
3. Нажмите «Рассчитать минимальные припуски». Результат показывает Zmin,
   погрешность установки и остаточное пространственное отклонение после
   каждого перехода.
4. На вкладке «Размерная цепь» добавьте поверхности и связи между ними.
   Для каждой связи задаются обозначение, тип (технологический размер,
   конструкторский размер или припуск), поверхности начала и конца,
   номинал и верхнее/нижнее отклонения. Схема обновляется при вводе.
5. Нажмите «Сохранить исходные данные». Данные хранятся отдельно для каждой
   версии STEP-модели в data/analysis.

Расчётное ядро использует единицы мкм для Rz, T, ρ, ε и Zmin, миллиметры
для длины и размеров. Для вращательных размеров применяется формула
Zmin = 2(Rz + T + sqrt(ρ² + ε²)); для линейных — Zmin = Rz + T + ρ + ε;
для полирования/суперфиниша — Zmin = 2Rz. Формулы и табличные исходные
значения должны быть подтверждены технологом для конкретного типа заготовки,
материала и операции. Расчёт межпереходных номиналов, допусков и полной
проверки цепи пока не реализован.

Цвета в окне модели:
- жёлтый — выбранная сейчас цилиндрическая поверхность;
- серо-голубой — цилиндрическая поверхность без назначенного квалитета;
- разные цвета — поверхности с назначенными квалитетами;
- светло-серый — остальные грани детали.

Командная версия
----------------
Для прежнего вывода в консоль выполните:
   python tolerance_finder.py

Ограничения текущей версии
--------------------------
- Номинальный размер пока предлагается округлением диаметра до целого мм.
- Разделение отверстий и валов использует ориентацию грани как эвристику.
- Номер грани связан с конкретным STEP-файлом; при изменении модели
  её назначения загружаются отдельно.
